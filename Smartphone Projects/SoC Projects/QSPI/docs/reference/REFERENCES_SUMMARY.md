# Reference Documents

This folder stores the board and flash-memory references used while developing and testing the QSPI IP.

- `flash_datasheet.pdf` - local copy of the flash memory datasheet.
- `nexys-a7-reference-manual.pdf` - official Digilent Nexys A7 FPGA Board Reference Manual PDF.
- `nexys-a7-reference-manual.url` - shortcut to the Digilent reference-manual website.
- `nexys-a7-sch.pdf` - official Digilent Nexys A7 FPGA board schematic PDF.
